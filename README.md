# 输液提醒小助手

## 打开方式

无需安装或构建。用现代浏览器打开仓库中的 `index.html` 即可使用。页面的 Tailwind 样式通过 CDN 加载，因此完整样式需要网络连接。

## 算法假设

用户选择预设容量后，手动点击水滴按钮记录 20 次滴液。页面按首末点击之间的平均间隔估算滴速（滴/分钟），再按固定 **20 滴/ml** 计算体积流速和预计时长，并据此显示估算结束时间。

## 重要限制

本工具仅用于演示和估算，不用于临床决策或调节输液。固定 20 滴/ml 只是本页假设；实际滴系数与输液速度必须由医护人员依据所用输液器规格确认。人工点击、测量误差及其他实际情况都会影响估算。请勿依赖页面结果作为治疗或护理指示；输液相关判断和操作应遵循医护人员指导。
